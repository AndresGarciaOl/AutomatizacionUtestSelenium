# Automatización de Registro en uTest

Este proyecto contiene un script de automatización desarrollado en Python utilizando Selenium WebDriver para el proceso de registro en la plataforma uTest.

## Tecnologías Utilizadas
* Python 3.12
* Selenium WebDriver
* WebDriver Manager (Chrome)

## Características del Script
* Manejo de esperas explícitas (WebDriverWait).
* Cambio dinámico entre pestañas/ventanas.
* Interacción con elementos mediante selectores de Clase, ID y XPATH.
* Ejecución de clics forzados mediante JavaScript para evitar bloqueos por CSS.

## Cómo ejecutar
1. Clonar el repositorio.
2. Instalar dependencias: `pip install selenium webdriver-manager`.
3. Ejecutar: `python test_utest.py`.
